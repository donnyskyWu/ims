## 2. 工作方法（已定，勿改）

1. **一个模块一批、一次做完**：每批交给一个编码会话一次做完，不拆小切片、不多路并行，批次严格串行，顺序 B10→B29。
2. **材料已审**：B10～B29 的 `01-功能点清单`、`02-业务E2E用例`、`03-评审记录` 已由 zhang wu 于 2026-10-13 审过。各批文件保持交审原文（03 表内仍可能写「待审」），审过结论以本指南为准，直接编码。
3. **按功能点实现**：严格按 01 清单逐条实现，每批产出对照表 `v2/docs/B<NN>-M<nn>-对照表.md`（功能点 → 实现位置 → 状态）。
4. **提测前只做快速验证**：只跑本批接口单测和路由冒烟。**不跑**全量 Playwright 和业务 E2E，这部分由测试工程师按用户操作执行。
5. **提测与收尾**：编码完成后开 PR 到 `main`。一批完成后告诉 Grok Bot 做合入、部署 8090、补种子。修复后只回归登记过的 bug。
6. **需求问题**：先由产品经理裁定，裁定不了交给 zhang wu。
7. **全部完成后做 UAT**，通过即交付；UAT 允许遗留的 P2 不超过 5 个。

## 3. 硬约束（每批都适用）

1. 只改 `v2/`，旧代码（`ims-backend/`、`ims-web/`）不动。
2. API 前缀 `/admin-api/ims/`；所有 ID 以字符串传给前端（雪花 ID 超过 2^53）。
3. 主库 `imsV2.0`；Alembic 只加不减；**不建物理外键**；保证 `alembic heads` 只有一个 head（多 head 先加空 merge revision）。
4. 无权限的按钮不渲染；离职员工完全禁止登录；权限按权限码配置，不按角色名硬编码。
5. 前端只用 B0b 已建的通用组件，不新造通用组件。
6. 分支从最新 `main` 拉，命名 `feat/b<NN>-<模块>`；PR 开到 `main`，标题含批次号和模块名（如「B10：AI 资源中心」）。
7. **不写任何密钥**。数据库密码、测试密码、API Key、连接串一律不进仓库、不进文档、不进提交说明和 PR 描述，只通过环境变量注入。
8. **跑会 TRUNCATE 的 pytest 之前，必须先 unset 云库 `DB_*` 环境变量（含 `IMS_DB_*`），只打本地 test 库。** `v2/ims-backend/tests/conftest.py` 会在用例前 `TRUNCATE` 当前连接上的表。环境变量能覆盖 `config/test.yaml` 的库地址；云库的 `DB_HOST`、`DB_NAME`、`DB_USER`、`DB_PASSWORD` 以及对应的 `IMS_DB_*` 若留在环境里，TRUNCATE 会打到云库。曾经因此清空过云库。跑之前执行：
   ```bash
   unset DB_HOST DB_PORT DB_USER DB_PASSWORD DB_NAME \
         IMS_DB_HOST IMS_DB_PORT IMS_DB_USER IMS_DB_PASSWORD IMS_DB_NAME
   ```
   确认进程连的是本地 test 库后再跑本批接口单测。
9. 外部环境：钉钉、内容 AI、数据采集用真实环境，其余用模拟接口；Football 直播表在开发测试环境用替身表。

## 4. 每批步骤

下一批是 **B10 AI 资源中心**。材料目录：`docs/ims-v2-rewrite/modules/B10-M10AI资源中心/`。之后每一批只替换批次号和目录，顺序固定为 B10→B29，一批合入后再开下一批。

1. 拉最新代码并建分支（`<NN>` 为两位批次号，`<模块>` 为模块简称）：
   ```bash
   git checkout main && git pull
   git checkout -b feat/b<NN>-<模块>
   ```
   B10 示例：`feat/b10-ai资源中心`。
2. 读本批三份材料：`01-功能点清单.md`、`02-业务E2E用例.md`、`03-评审记录.md`。以 01 为准逐条实现，02 作验收依据，03 的裁定必须遵守。
3. 只改 `v2/`。
4. 只跑本批接口单测和路由冒烟，不跑全量 E2E。跑会 TRUNCATE 的 pytest 前，先按第 3 节 unset 云库 `DB_*`，只打本地 test 库。
5. 推送并开 PR 到 `main`：
   ```bash
   git push -u origin feat/b<NN>-<模块>
   ```
   标题示例：「B10：AI 资源中心」。
6. **一批完成后告诉 Grok Bot**：本批 PR 已开好，请做合入、部署 8090、补种子。这三件事由 Grok Bot 做，本地编码会话不做。

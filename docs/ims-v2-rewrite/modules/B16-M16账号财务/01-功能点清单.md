## 1. 账号成本登记（COST-001 / P1）

### AC-01 选账号与成本总览
- **入口**：侧栏「账号财务」→ Tab「成本登记」；AccountSelect（仅平台账号，排除个人账号 S-03）。
- **权限**：`ims:cost:account:query`。
- **字段**：账号编号/昵称/平台/IP 组/作者/状态；采购金额；过程合计；总成本。
- **接口**：`GET /admin-api/ims/cost/account/{accountId}`。
- **依据**：COST P1；契约 §1 #1。

### AC-02 采购成本 upsert
- **入口**：成本登记区「采购成本」卡片 [编辑]。
- **权限**：`ims:cost:account:write`。
- **字段**：金额*（>0）、发生日期*、经办人*（默认当前用户）、备注≤256；`X-Client-Token`。
- **规则**：每账号仅一条采购行；再次保存覆盖；清空金额视为删除该行【本清单裁定，S-06】。
- **错误码**：1231、1001、1500/1501。
- **接口**：`PUT /admin-api/ims/cost/account/{accountId}/purchase`。
- **组件**：FormDrawer、MoneyText、UserSelect、DateRangePicker（单日）。

### AC-03 过程成本新增 / 编辑 / 删除
- **入口**：过程成本表 [新增] / 行 [编辑] / [删除]。
- **权限**：写同上。
- **字段**：类型*（字典）、金额*（>0）、周期起止*（起≤止）、经办人*、备注。
- **删除**：ConfirmDialog；已引用到场次财务的过程行本批**无跨模块引用**，直接删【本清单裁定，S-07】。
- **接口**：`POST/PUT/DELETE /admin-api/ims/cost/account/{accountId}/process`（PUT/DELETE 带 `processId`）。
- **依据**：契约 §1 #3。

### AC-04 成本合计与空态
- **计算**：`totalCost = purchase.amount + Σ process.amount`（两位小数，BigDecimal）。
- **空态**：未选账号 EmptyState「请选择平台账号」；无成本「暂无成本，可登记采购或过程成本」。

## 2. 账号 ROI（COST-002 / P2）

### ROI-01 多维查询
- **入口**：Tab「账号 ROI」。
- **权限**：`ims:cost:roi:query`。
- **查询**：维度*（公司/IP组/账号/人员）、日期范围*、公司/IP组/账号/人员可选过滤。
- **列**：维度名、成本、营收、ROI（营收/成本，成本为 0 时显示「—」不除零【本清单裁定，S-08】）、营收状态 tag。
- **页头**：固定文案「账号粒度；营收来自 Football 订单 WebAPI 日汇总（本环境为模拟）」。
- **接口**：`GET /admin-api/ims/cost/roi`。
- **依据**：COST P2；BR-302。

### ROI-02 趋势与成本结构
- **入口**：ROI 页下区图表（可选折叠）。
- **接口**：`GET /admin-api/ims/cost/roi/trend`、`GET /admin-api/ims/cost/roi/breakdown`。
- **组件**：Chart（UI-C40）。
- **依据**：契约 §3 R2/R3。

### ROI-03 导出
- **权限**：`ims:cost:roi:export`。
- **接口**：`POST /admin-api/ims/cost/roi/export` → 导出中心异步任务。
- **R9**：导出文件金额列仍为 `***` 或不含金额列【本清单裁定，S-09：导出不含金额明文】。

### ROI-04 营收延迟表现
- **规则**：Football 超时 / 失败 → 行或页头黄条「营收延迟」，营收列显示「—」与 tag DELAYED，**禁止写 0**；成本列仍可算。
- **错误码**：列表接口整体超时返回 1232；部分维度失败标记 DELAYED 不整页失败【本清单裁定，S-10】。

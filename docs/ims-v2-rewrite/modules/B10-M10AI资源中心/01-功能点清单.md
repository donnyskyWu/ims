## 2. 技能库 `/ims/air/skill`（【AIR】P1；SKILL-001～004）

### FP-B10-SK-01 列表与分类页签
- **入口**：侧栏「技能库」。
- **字段和校验**：QueryBar＝名称 / 状态 / 审核状态 / 责任人；CatTabs＝分类（含「全部」）；列＝编号、名称、分类、版本、状态、风险、责任人、更新时间、操作。
- **计算规则**：分页默认 20；状态/风险中文；ID 字符串等宽。
- **B0b**：CatTabs、QueryBar、DataTable、Pagination、StatusTag。
- **依据**：V2 P1 §5～6。

### FP-B10-SK-02 新增技能（提交即进审核）
- **入口**：[新增技能] → FormDrawer 480。
- **字段和校验**：名称≤128、分类必选、版本语义化、来源三选一联动（UPLOAD→fileKey；URL→sourceRef URL；MARKET→市场标识）、能力说明、mdContent（SKILL.md）必填非空、责任人、clientToken。
- **状态流转**：提交 → `PENDING_AUDIT`；版本 `audit_status=PENDING`；**无独立草稿态**（规格：草稿语义并入待审核）【与建库口径区分：技能提交即审】。
- **计算规则**：提交后自动跑**模拟安全扫描**，写 risk_level + scan_json（依赖/危险命令/外链三清单）；P0/P1/P2 规则本批用启发式（如 md 含 `rm -rf` / 外链非白名单 → 升风险）【本清单裁定，S-08】。
- **错误码**：1001。
- **接口和表**：POST `/air/skill`；ims_skill + ims_skill_ver。
- **B0b**：FormDrawer、FormField、FileUpload、UserSelect、DictSelect。
- **依据**：V2 P1 4.2A；BR-025/026。

### FP-B10-SK-03 编辑技能（新版本重审）
- **入口**：已发布/退回可改行 [编辑]。
- **计算规则**：生成新版本 PENDING；旧已发布版本授权保持，新版本过审后切绑；REJECTED 不可编辑再提【BR-025】。
- **错误码**：1001、1008。
- **接口和表**：PUT `/air/skill/{id}`。

### FP-B10-SK-04 技能审核抽屉（REV-R1）
- **入口**：待审行 [审核] → Drawer 560。
- **角色权限**：`ims:air:skill:audit`（R1/R11）；**提交人=当前用户 → 按钮隐藏/禁用，服务端 1057**【已定】。
- **字段和校验**：只读基础信息 + 扫描三清单 + 风险；[审核通过] / [驳回·永久拒绝] / [退回修改]；**驳回与退回意见必填**；P0 时 [审核通过] 禁用，仅可永久拒绝。
- **状态流转**：通过→PUBLISHED+APPROVED；REJECT→REJECTED 终态；RETURN→仍 PENDING_AUDIT（内容可再编辑提交）。
- **错误码**：1001（无意见/P0 强行通过/重复审）、**1057**。
- **接口和表**：POST `/air/skill/{id}/audit`。
- **B0b**：FormDrawer、ConfirmDialog（requireReason）、StatusTag。
- **依据**：V2 P1 §7；REV-R1；已定口径。

### FP-B10-SK-05 技能授权 / 收回
- **入口**：已发布行 [授权]；未过审锁定【BR-025】。
- **字段和校验**：grantType + 对象（Dept/Role/User）+ 有效期可选 + 全员开关；列表可收回→REVOKED。
- **计算规则**：写 ims_air_event；提示「生效延迟 <5 分钟（BR-024）」；本批无 MCP，事件仅落库。
- **错误码**：1001（非 PUBLISHED）、1500。
- **接口和表**：POST `/air/skill/grant`；DELETE `/air/skill/grant/{grantId}`。

### FP-B10-SK-06 启停与详情
- **入口**：[停用]/[启用]；行点击详情 Drawer 60%。
- **计算规则**：DISABLED 后对后续连接器不可见（本批无 MCP，仅状态）；详情含 SKILL.md 预览 + 版本史。
- **接口和表**：PUT `/air/skill/{id}/status`；GET `/air/skill/{id}`。
- **B0b**：DetailDrawer、Timeline、ConfirmDialog。

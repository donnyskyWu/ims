### 0.3 本批角色与权限码
权限按**权限码**配置，禁止按角色名硬编码（A-07）；种子授予标准角色。**无权限按钮不渲染**；**离职禁止登录**（B1-D1 / 1216）。

| 权限码 | 含义 | 种子授予 |
|--------|------|----------|
| `ims:ip-group:query` | 查看树 / 详情 / 成员 / 账号 / 作者关联 / 统计 | R1/R2/R3/R4/R5/R6/R7/R9（R5/R6/R7 数据范围「所属 IP 组」） |
| `ims:ip-group:create` / `update` / `delete` | 新建 / 编辑 / 停用删除组 | R1/R4 |
| `ims:ip-group:member` | 成员增删改 | R1/R4；R5 本组（持码且数据范围命中） |
| `ims:ip-group:account` | 账号绑定 / 解绑 | 同 member |
| `ims:ip-group:anchor` | 关联作者 / 设主作者 | 同 member |
| `ims:ip-group:author:query` / `create` / `update` / `delete` | 作者管理独立列表 | query：同 ip-group:query；写/删：R1/R4 |
| `ims:ip-group:author:export` | 作者列表导出 | R1/R4（可选；默认开放给 R1/R4） |

- **数据范围**：角色 `data_scope=IP_GROUP` 时，树与列表仅 `accessible-tree` / 本组及（大组视角下）可见子组；`ALL` 看全量。成员表 `ims_ipg_member.user_id` 与组长写入 `ims_user_scope`（B0a 已有机制）供范围解析。
- R9 只读：可见，无写按钮。R8/R10 无「IP 组」菜单。

## 1. IP 组运营 · 树与基本信息 `/ims/ip-group`（【IPG】P1；IPG-001）

**页面线框**：页内 Tabs「IP 组运营 | 作者管理」。运营视图：左栏「IP 组结构」+ 搜索「搜索组名」+ 树（大组→小组，节点文案 `组名 (成员数/账号数/作者数)`，有等级后缀 `[S/A/B/C级]`）+ 树标题栏「+ 新建大组」；右栏选中后详情头（类型 Tag、组名、组长|上级|创建于、操作 编辑/停用/删除）+ 5 Tab。未选中：EmptyState「请从左侧选择 IP 组」。空树：左栏空态 +「新建大组」（BUG-026）。

### FP-B8-TR-01 全量树与可访问树
- **角色权限**：`ims:ip-group:query`。
- **计算规则**：管理员 / `ALL` → `GET …/tree`；`IP_GROUP` 范围 → `GET …/accessible-tree`（仅可见组及其为展示完整路径所需的祖先大组，祖先只读不可操作【本清单裁定】）。
- **接口和表**：`GET /admin-api/ims/ip-group/tree`；`GET /admin-api/ims/ip-group/accessible-tree`；`ims_ipg_group`。
- **B0b 组件**：EmptyState、StatusTag。
- **依据**：IPG 契约 #1/#1b；BUG-025/026。

### FP-B8-TR-02 组名搜索
- **字段和校验**：左栏搜索框，按组名模糊；命中小组时展开父大组并高亮（BUG-025）。
- **计算规则**：无命中 EmptyState「无匹配的 IP 组」。

### FP-B8-TR-03 新建大组
- **角色权限**：`ims:ip-group:create`。
- **字段和校验**：组名* 1～50 字；等级可选；组长可选（UserSelect 在职）；备注 ≤255；类型固定 BIG，上级空。
- **计算规则**：同级（parent 空）组名唯一 → 重名 1001；写时间线 CREATE。
- **错误码**：1001、1204、1503。
- **接口和表**：`POST /admin-api/ims/ip-group/create`（`X-Client-Token`；`groupType=BIG`）。
- **B0b 组件**：FormDrawer、UserSelect、DictSelect。

### FP-B8-TR-04 新建小组
- **入口**：选中大组后详情头或树节点「+ 新建小组」。
- **字段和校验**：组名*；上级* TreeSelect 仅 BIG（默认当前大组）；组长可选；等级可选；备注。
- **计算规则**：上级必须存在且为 BIG，否则 1001；同父组名唯一；`groupType=SMALL`。
- **错误码**：1001、1204、1500、1501。
- **接口和表**：同 create（`groupType=SMALL`）。

### FP-B8-TR-05 编辑基本信息
- **角色权限**：`ims:ip-group:update`。
- **字段和校验**：可改组名、等级、排序、备注、组长、状态；小组可改上级（仅 BIG、非自己/子孙）；**组类型不可改**；大组 `parentId` 必须空。
- **接口和表**：`PUT /admin-api/ims/ip-group/update`。

### FP-B8-TR-06 停用 / 启用
- **计算规则**：停用后：IpGroupSelect 新建场景不可见；已绑账号保留关系但选择器按 1501 拦截新绑；树节点灰色 Tag「停用」。
- **接口和表**：含在 update（`status`）。

### FP-B8-TR-07 删除组
- **角色权限**：`ims:ip-group:delete`。
- **计算规则**：存在成员 / 账号（`ip_group_id`）/ 关联作者 / 子小组 → **1206**；大组有子小组时先删子；ConfirmDialog。
- **错误码**：1206、1008。
- **接口和表**：`DELETE /admin-api/ims/ip-group/delete?id=`。

### FP-B8-TR-08 详情头与基本信息 Tab
- **字段和校验**：DescriptionList：组名、类型、上级、组长、等级、状态、排序、备注、创建/更新时间（北京时间）。
- **接口和表**：详情可由 tree 节点 + `GET …/list` 或选中后聚合；列表 `GET /admin-api/ims/ip-group/list`（keyword/groupType/status）备用。

## 3. 账号绑定 Tab（IPG-003）

### FP-B8-ACC-01 已绑账号列表
- **角色权限**：`ims:ip-group:query`。
- **字段和校验**：列：账号编号、昵称、平台、状态、责任人、作者（物化名或 —）、操作[解绑]。
- **计算规则**：大组 Tab 只读提示「请在小组下绑定账号」+ 可展示子组账号汇总只读【本清单裁定：大组仅汇总只读，写操作禁用】。
- **接口和表**：`GET /admin-api/ims/ip-group/{id}/accounts`（**全系统实体→账号级联统一数据源**）。

### FP-B8-ACC-02 绑定账号
- **角色权限**：`ims:ip-group:account`。

## 5. 账号 → 作者解析与 1223（MASTER；B7 S-05 本批强制）

### FP-B8-B7-01 解析优先级（服务端统一 `resolveAuthorId`）
```
1. account.author_user_id 非空 → 采用（人工/已物化）
2. account.ip_group_id → 组内 is_primary=1 的作者 → 采用
3. 组内作者数 = 1 → 采用该唯一作者
4. 组内作者数 = 0 → 1223（未配置映射）
5. 组内作者数 ≥ 2 且无主作者 → 1223（不唯一）
```
**禁止**取第一条/最小 id 猜测。

### FP-B8-B7-02 写账号强制点
- **入口**：B7 `POST/PUT /corp/account`；本批 `POST …/ip-group/{id}/accounts`。
- **计算规则**：
  1. **新建平台账号**：`ipGroupId` **必填**且必须为启用中的 SMALL（【本清单裁定，落实 MASTER「强关联选择器」+ S-05】）；保存时跑解析，成功则写 `author_user_id`，失败 → **1223**。
  2. **编辑账号**：若提交/已有 `ipGroupId`，同样校验；允许在表单用 AuthorSelect **显式指定** `authorId`（最高优先）。
  3. **历史空 IP 组账号**：仍可打开；首次编辑保存时按必填校验（须补选小组）。
  4. 个人账号、领用/流转/归还逻辑不变；离职归还仍**只收集平台账号**（B7 边界）。
- **错误码**：1223、1203（误选大组）、1500、1501。

### FP-B8-B7-03 账号表单 UI 回补
- **计算规则**：五平台登记/编辑抽屉：展示 IpGroupSelect*（仅 SMALL）、AuthorSelect 可选；详情 DescriptionList 展示「IP 组」「作者」；去掉「IP 组模块上线后可绑定」占位文案。
- **依据**：B7 PA-02/PA-04 回补。

### FP-B8-B7-04 AccountSelect 增筛
- **计算规则**：AccountSelect 已有 `ipGroupId?`；本批保证按组过滤真实可用（含仅本小组已绑）。

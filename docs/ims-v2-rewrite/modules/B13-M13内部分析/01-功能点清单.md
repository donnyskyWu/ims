## 0. 约定

### 0.1 编号
`FP-B13-WORK-*`、`FP-B13-ACCT-*`、`FP-B13-IMP-*`（补录）、`FP-B13-UP-*`、`FP-B13-BG-*`。

### 0.2 范围

| 类别 | 内容 |
|------|------|
| 侧栏 | L1「日常运营」→ L2「内部分析」2 叶：**内部作品** `/ims/int-analysis/work`、**内部账号** `/ims/int-analysis/account`；`/ims/int-analysis` → work |
| P1 作品 | Tab：**全部 / 爆款 / 低分**（名不可改）；筛选平台、**IP 组**、内容类型、日期、关键词；汇总卡；详情趋势；导出 |
| P2 账号 | Tab：**全部 / 高粉 / 低粉**；筛选平台、IP 组、状态；汇总卡；详情；导出 |
| IPG-005 落地 | 账号/粉丝/作品/内部内容分析能力由本两页承载；**按 IP 组筛选**【已定 A-10 / B8】 |
| 补录 | 工具栏「数据补录」→ 导入向导（非主导航）；`POST …/internal-content/import` 语义 |
| **不做** | MON 的 IP 主题/行业（B15）；竞品外部盘（B14）；在 IP 组模块做分析页 |
| 阈值 | **只读引用** B12 阈值；顶栏链至 `/ims/collect/threshold` |
| 复用 | B0b StatCard/Chart/QueryBar/DataTable/ExportButton/IpGroupSelect/AccountSelect/DictSelect；B8 IP 组；B12 数据 |
| E2E | `b13.py` |

### 0.3 权限码
`ims:int:work:query` / `export`；`ims:int:account:query` / `export`；`ims:int:work:import`（补录）。
种子：R1/R4/R5（IP 组范围）/R6/R9；补录 R1/R4。

### 0.4 错误码
通用 1001/1008/1500～1504；监测段引用 **1251** 阈值未配置（列表空态提示链阈值页，不硬拦）。

### 0.5 表
本批**以读 B12 内部内容/账号快照与粉丝日表为主**；补录写入 `ims_internal_content`（或等价 Channel-A 补录表）：title、account_id、platform、metrics、ip_group_id、source=MANUAL、tenant_id。不建物理外键。可选 `ims_int_export_job` 走通用导出中心。

### 0.6 字典
标签：爆款/低分/正常；高粉/低粉/正常（展示用，可由阈值计算，不强制新字典）。

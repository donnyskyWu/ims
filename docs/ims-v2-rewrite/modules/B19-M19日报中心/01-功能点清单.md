# B19 · M19 日报中心 · 01 功能点清单

> 版本：v1.0 · 2026-10-13 · 编写：IMS 产品经理 · 状态：**待 zhang wu 评审**
> 上游：03 M19；05 B19（依赖 B2/B3；接口 15 → 本批 **20**；工期约 5～9 开发日）；规格 **V2**【MEET】P1～P3 + API 日报/审阅/统计段；裁定 **B074** 三态；**D-07 / FW-H07** 钉钉考勤独立应用（开发期模拟）；04 A-08（取消退回/已补交）。
> **已定口径**：① 日报三态 **草稿 / 已提交 / 已审阅**（枚举 DRAFT/SUBMITTED/REVIEWED；契约历史名 READ 统一为 REVIEWED 展示「已审阅」）。② **按时/迟交** 仅为 `isOnTime` 标签列，**不设**「已补交」「已退回」状态。③ 截止默认 **当日 22:00**（部门模板可覆盖）。④ 应提交天数 = **工作日 − 节假日**（考勤启用后另减请假；开发期考勤**模拟**，未启用时不扣请假）。⑤ 审阅动作：已读 / 点评 / 标记跟进（无退回改正文）。
> 会议纪要归 B18。库 `imsV2.0`；无物理外键；ID 字符串；不改 deploy-b4；无密钥。

## 0. 约定

### 0.1 编号
`DLY` 填写与我的日报、`REV` 审阅、`STAT` 统计、`UP`/`BG`。

### 0.2 范围

| 类别 | 内容 |
|------|------|
| 侧栏 | 「协同与成长 / 日报中心」4 叶：我的日报 `/ims/daily/mine`、团队日报 `/ims/daily/team`、待我审阅 `/ims/daily/review`、提交率统计 `/ims/daily/stat` |
| 填写 | 三段式（完成/计划/问题）+ 周五周小结；草稿自动保存；提交 |
| 审阅 | 一级/二级；已读/点评/跟进；无退回状态 |
| 统计 | 按时率 BR-103、人月提交率 BR-104、未交迟交清单、审阅及时性 |
| 考勤 | FW-H07 独立配置 + 模拟；工作日历种子 |
| **不做** | 会议（B18）；真实考勤联调（可配置切换）；「已补交/已退回」 |

### 0.3 权限码
`ims:daily:mine:write`（本人）；`ims:daily:team:query`（R1 全量/R2 本部门/R4 下属+本部门/本人）；`ims:daily:review`（一级上级/R4）；`ims:daily:stat:query`（R1/R2/R9/R4 本部门/本人）。

### 0.4 错误码
1111 一人一日一份；1112 已提交不可改正文（走补充说明）；1113 越级审阅；1114 非审阅人；1115 非跟进责任人；1001；考勤降级提示非错误码。

### 0.5 表
`ims_daily_report`（user_id+report_date 唯一、三态、is_on_time、content_*、week_summary、supplement、submitted_at）；`ims_daily_review`；`ims_daily_follow_up`；`ims_daily_template`（部门截止时刻默认 22:00）；`ims_daily_stat`（日/月汇总）；工作日历复用 B0a/B2 日历表；考勤请假模拟表或适配器缓存。

### 0.6 状态机（B074）
```
DRAFT --提交--> SUBMITTED --审阅动作--> REVIEWED
         ^                |
         |---- 仅补充说明（不改三态核心，正文锁）【S-01】
```
- 提交时刻 ≤ 截止 → isOnTime=true，否则 false（迟交标签）。逾期仍可提交，**不**新增状态。
- 审阅：READ→展示已审阅；COMMENT/MARK_FOLLOW_UP 亦置 REVIEWED（若尚未）【本清单裁定，S-02：任一审阅动作→已审阅】。

## 1. 我的日报（DLY）

### DLY-01 当日填写页
- 入口：我的日报 [写今日] 或工作台待办；移动端优先布局。
- 三段必填；周五周小结；自定义字段按模板；截止倒计时。
- 30s 自动草稿；提交 ConfirmDialog（逾期黄条「将标记迟交」）。
- `POST /meet/daily`；`GET /meet/daily/{date}`；`GET /meet/daily/template`。

### DLY-02 我的列表与历史
- 近 N 日状态 tag + 按时/迟交列；无「已补交/已退回」。

### DLY-03 已提交补充说明
- `PUT` 仅 supplement；1112 拦正文。

### DLY-04 一人一日（1111）
- 唯一约束。

---

## 2. 团队日报与审阅（REV）

### REV-01 团队列表
- 筛选人员/部门/日期/状态；摘要列；按时列。

### REV-02 审阅队列
- 一级/二级；徽标待审数；`GET /meet/review/queue`。

### REV-03 审阅动作
- 已读 / 点评（comment）/ 标记跟进（followUpItems 必填）；**无退回按钮**。
- `PUT /meet/review/{reportId}`。

### REV-04 跟进闭环
- `PUT /meet/review/follow-up/{itemId}` → B3 待办。

### REV-05 审阅记录
- `GET /meet/review/records`。

---

## 3. 统计（STAT）

### STAT-01 按时率（BR-103）
- `GET /meet/stat/on-time-rate`；目标>95%。

### STAT-02 人月提交率（BR-104）
- shouldDays：工作日−节假日（−请假若考勤启用）；悬浮明细；考勤失败黄条降级文案。
- `GET /meet/stat/monthly`。

### STAT-03 未交/迟交清单
- `GET /meet/stat/missed`；导出。

### STAT-04 审阅及时性
- `GET /meet/stat/review-timeliness`。

---

## 4. 考勤与日历（BG/UP）

### BG-01 FW-H07 落地
- 独立配置项（与 IMS 钉钉应用分离）；模式模拟/真实；密钥加密脱敏；**文档不写密钥**。
- 模拟：请假条种子。

### BG-02 工作日历种子
- 当年法定节假日与调休；B2 可维护。

### UP-01 B3 日报待办
- 每日调度生成「写日报」待办（截止前 1h 提醒可模拟/钉钉真实通知按 D-06 IMS 应用）。

### UP-02 B2 菜单四叶 + 权限 + 字典 `dict_daily_status`（草稿/已提交/已审阅）+ `dict_on_time`（按时/迟交）。

### BG-03 `b19.py` 造数：按时、迟交、草稿、待审、已审阅各样本。

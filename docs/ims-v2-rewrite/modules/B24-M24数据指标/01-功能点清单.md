## 1. 指标管理 `/ims/bi/metric`（BI0 P1）

### FP-B24-MT-01 列表与筛选
- **入口**：侧栏「指标管理」。
- **字段**：QueryBar＝名称/编码、类型、分类、状态；列＝ID、名称、编码、类型、分类、数据源、公式摘要、频率、单位、状态、更新时间、操作。
- **B0b**：QueryBar、DataTable、Pagination、StatusTag。
- **依据**：V1 P1 §2.3。

### FP-B24-MT-02 新建 / 编辑指标
- **入口**：[新建指标] / 行 [编辑] → FormDrawer 960。
- **字段和校验**：名称≤128；编码必填唯一（租户内）；类型 BASIC→Builder（数据源/计算方式/字段/汇总/条件）；COMPOSITE→数据源+公式手输；分类、频率、单位必选；描述可选；`X-Client-Token`。
- **状态流转**：保存默认 ENABLED；可停用。
- **错误码**：1001（编码重复/公式非法）、1503。
- **接口**：POST/PUT `/admin-api/ims/bi/metric`。
- **B0b**：FormDrawer、FormField、DictSelect。
- **依据**：V1 P1；BIR-R3 口径只在本页维护。

### FP-B24-MT-03 试算预览
- **入口**：抽屉内 [预览]。
- **计算规则**：执行 preview SQL/Builder，**≤20 行**内联面板；超时提示缩小条件；只读库账号（与 B26 SQL 安全同策略子集）【裁定 S-05】。
- **接口**：POST `/admin-api/ims/bi/metric/preview`。

### FP-B24-MT-04 启停
- **入口**：行 [停用]/启用]。
- **计算规则**：停用后新建报表/查询不可再选；**已引用处仍可读历史定义**（快照或继续读当前公式——默认**继续读当前定义**并在引用侧展示「已停用」角标）【裁定 S-06】。
- **接口**：PUT `/admin-api/ims/bi/metric/{id}/status`。

### FP-B24-MT-05 删除（引用 → 1502）
- **入口**：行 [删除] → ConfirmDialog。
- **计算规则**：查 `ims_bi_metric_ref` 及消费侧登记；有任一引用 → **1502**「存在关联数据，无法删除」，弹窗列出引用类型与名称；无引用可删（逻辑删除）。
- **错误码**：**1502**【已定】。
- **接口**：DELETE `/admin-api/ims/bi/metric/{id}`。
- **依据**：用户已定；V1「删除/停用前引用保护」。

### FP-B24-MT-06 导出指标台账
- **入口**：[导出]。
- **接口**：走导出中心；权限 `export`。

## 2. 指标分析 `/ims/bi/metric-analysis`（BI0 P2）

### FP-B24-AN-01 指标明细 Tab
- **入口**：侧栏「指标分析」默认 Tab。
- **字段**：选指标（多选≤5）、日期范围、时间维度 DAY/WEEK/MONTH、IP 组/平台（有则显示）；明细表按维度展开。
- **接口**：GET `/admin-api/ims/bi/metric/{id}/analyze?mode=detail`。
- **B0b**：Tabs、QueryBar、DataTable、DateRangePicker、IpGroupSelect。

### FP-B24-AN-02 指标趋势 Tab
- **计算规则**：折线/柱图展示趋势；空数据 EmptyState。
- **接口**：analyze `mode=trend`。
- **B0b**：Chart。

### FP-B24-AN-03 分析导出
- **入口**：[导出]；异步导出中心。

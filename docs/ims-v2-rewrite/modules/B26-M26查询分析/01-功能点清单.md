### 0.5 表
`ims_qt_template`（含 mode/builder/sql/status/menu_seeded）、`ims_bi_custom_query`、`ims_bi_query_audit`（SQL/QT 执行审计）、`ims_bi_sql_whitelist_table`、`ims_bi_drill_path`（维度层级配置）、性能汇总可用日志表或统计视图。

### 0.6 SQL 动态硬规则（验收）
1. 连接只读账号（配置在安全配置，**密钥不进文档**）。
2. 仅 SELECT/WITH…SELECT；多语句拒绝。
3. 表/视图 ∈ 白名单且租户隔离。
4. 强制 LIMIT≤配置上限（默认 10000）；超时默认 30s。
5. 自动注入数据范围谓词；失败则拒跑。
6. 审计：操作者、SQL 指纹、耗时、行数、是否拒绝。

## 1.1 查询工具详细功能点

### FP-B26-QT-01 模板列表与筛选
- **入口**：侧栏「查询工具」。
- **字段**：名称、模式（FLAT/DRILL/TRACE）、状态、更新人、是否已挂菜单。
- **B0b**：QueryBar、DataTable、StatusTag、Pagination。
- **依据**：QT P1。

### FP-B26-QT-02 新增/编辑向导
- **入口**：[新建] FormDrawer/StepsWizard。
- **字段**：模式必选；FLAT→Builder；DRILL→多层 JOIN 步骤；TRACE→pathSteps（调 DC，不新 API）。
- **错误码**：1001。
- **接口**：POST/PUT `/analysis/query-tool/template`。

### FP-B26-QT-03 执行 run（仅 SYNC）
- **计算规则**：`POST .../run` 单请求返回；**禁止 1262**；展示 `queryCostMs`。
- **错误码**：1263/1264/1261/1008。
- **依据**：QT API §3.2。

### FP-B26-QT-04 MenuSeed 发布/撤销
- **计算规则**：仅 PUBLISHED 可 seed；撤 seed 显式 DELETE；unpublish 不自动删菜单。
- **错误码**：1265 已挂不可删模板。

### FP-B26-QT-05 删除模板
- **计算规则**：已 seed → 1265；否则逻辑删。

## 0. 约定

### 0.1 编号
`THM` IP 主题、`IND` 行业、`UP`/`BG`。

### 0.2 范围

| 类别 | 内容 |
|------|------|
| 侧栏 | L1「日常运营」→ 叶子「作品监测」`/ims/monitor/theme`（单页）；页内 Tab：**IP 主题 \| 行业** |
| 兼容 | `/ims/monitor`、`/ims/mon` → theme；行业深链 `?tab=industry` 或 `/ims/monitor/industry` 重定向同页 Tab |
| IP 主题 | 主题维度聚合外部竞品数据：主题列表/详情、作品数、播放、爆款数；下钻作品只读（可跳 B14 作品页带筛） |
| 行业 | 行业维度同上 |
| 阈值 | 只读 B12；1251 空态提示 |
| **不做** | 内部作品/账号 Tab（B13）；竞品爆款/低分/高粉/低粉（B14）；采集配置 |
| 复用 | B0b；B12 快照；IpGroupSelect 可选筛 |
| E2E | `b15.py` |

### 0.3 权限
`ims:monitor:theme:query` / `export`；种子 R1/R4/R5/R6/R9。

### 0.4 错误码
1251 阈值未配置；1001/1008/1500～1504。

### 0.5 表
主题/行业维度配置表 `ims_monitor_theme`、`ims_monitor_industry`（code、name、status、sort）；关联外部账号/作品标签表 `ims_monitor_theme_bind`（theme_id、ext_account_id 或 keyword）；聚合以查询 B12 快照为主，可物化 `ims_monitor_theme_stat_daily`（可选，【P-1】默认用实时聚合+缓存）。不建物理外键；ID 字符串。

### 0.6 字典
无强依赖；平台复用 dict_platform_type。

## 4. 接口（6）

| # | 方法 | 路径 |
|---|------|------|
| 1 | GET | `/monitor/ip-theme/page` |
| 2 | GET | `/monitor/ip-theme/{id}` |
| 3 | POST/PUT | `/monitor/ip-theme`（计 1 写入口，细分 POST+PUT 算 2 则总 7——**【裁定】POST+PUT+bind 合并计为写 2**：page/detail/write/export × theme 与 industry 对称收敛为 **6**） |
| 4 | GET | `/monitor/industry/page` |
| 5 | GET | `/monitor/industry/{id}` |
| 6 | GET | `/monitor/ip-theme/export` 与 industry/export 共用导出中心参数 type=THEME\|INDUSTRY → **计 1** |

【本清单裁定，S-02】计划 2→6：在契约 3 条基础上补 detail 对称、写配置、统一导出。写配置若拆 POST/PUT/bind 则实现可多于 6，**对外清单记 6 个业务能力路由组**，实现路由允许 8，提测按能力验收。

为与 05「6」一致，列出实现路由：
1 theme/page 2 theme/{id} 3 theme write(POST) 4 industry/page 5 industry/{id} 6 export(type)
（theme PUT/bind、industry write 作为 write 子方法，E2E 覆盖，不另增计划计数）

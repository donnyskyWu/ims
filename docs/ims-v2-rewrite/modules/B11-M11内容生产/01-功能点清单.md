## 1. SOP 管理 `/ims/content/sop`（CONTENT-100/001）

### FP-B11-SOP-01 SOP 列表与筛选
- **入口**：内容生产 → SOP管理。
- **字段和校验**：筛选名称、适用内容类型（dict_content_type）、状态、平台。
- **接口和表**：`GET /admin-api/ims/content/sop/page`；`ims_content_sop`。
- **B0b**：QueryBar、DataTable、StatusTag、DictSelect。
- **依据**：OPS 补充 §P-SOP；B001。

### FP-B11-SOP-02 新建/编辑 SOP（DAG 画布）
- **入口**：新建模板 / 编辑。
- **字段和校验**：名称*；**适用内容类型*（必填下拉，仅文章/短视频/视频）**【已定 B001】**；说明；节点≥1；节点类型三值；内容生成节点必填 document_type；needReview=1 时审核岗位必填；保存前校验无环、节点名不重复。
- **状态流转**：保存 → version+1；进行中项目沿用旧版本（SOP-R3）。
- **错误码**：1001、1500（缺执行岗位）。
- **接口和表**：`POST/PUT /admin-api/ims/content/sop`；节点/边表。
- **B0b**：FormDrawer（大抽屉/全屏）、FormField、DictSelect、ConfirmDialog。
- **依据**：UX-M2；ADR-074 营销计划属性在本页维护。

### FP-B11-SOP-03 查看节点 / 启停 / 删除
- **计算规则**：停用后新立项不可选，进行中不受影响；inProgressProjectCount>0 禁止删除（1502）。
- **接口和表**：`PUT …/sop/{id}/status`；`DELETE …/sop/{id}`；`GET …/sop/{id}`。

### FP-B11-SOP-04 预置标准流程种子
- **计算规则**：预置「标准内容生产运营流程」14 节点、4 路并行（推文/方案/视频/直播）；仅非生产可重置。
- **依据**：OPS 补充；BG。

## 4. 我的任务与执行（CONTENT-103）

### FP-B11-TSK-01 我的任务 / 全部任务
- **入口**：`/ims/content/task`；默认「我的任务」。
- **字段和校验**：筛选 IP 组、状态、执行人（全部 Tab）。
- **接口和表**：`GET /admin-api/ims/content/task/page`。

### FP-B11-TSK-02 任务执行全页
- **入口**：`/ims/content/task/:id/execute`。
- **字段和校验**：基本信息只读（**不展示 SLA**，ADR-080）；执行说明/参考附件只读；userAttachments 可增删；CONTENT_GENERATION 显示关联内容与 AI 状态；NORMAL 必填 deliverables；CONTENT_PUBLISH 占位文案。
- **接口和表**：`GET/POST …/task/{id}/execute`、`…/execute/save`。
- **B0b**：FileUpload、StatusTag、Tabs（多 IP 组并行时）。

### FP-B11-TSK-03 提交审核 / 完成门禁
- **计算规则**：CG 且内容 DRAFT/REJECTED 可提审；完成要求内容达 PENDING_PUBLISH 及之后（ADR-079），否则 1054；NORMAL 未填说明 1500。

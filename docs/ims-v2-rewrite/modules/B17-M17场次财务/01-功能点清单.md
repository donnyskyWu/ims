### 0.7 关键计算
- 佣金默认：`(gmv - refund) × commissionRate`（TC-00 C-23）。

- 分成：基数 × 比例；阶梯逐档求和（BR-109）；多对象比例和 = 1.0000（V2-E2）。
- 核准后 MQ/异步 ≤5 分钟算利润并生成分成单（FIN-P-R1 / FIN-S-R2）。

## 1. 成本录入 `/ims/fin/cost`（CST）

### CST-01 待录入清单与完整率
- 指标卡：已核准场次数、已录入、完整率（BR-107 目标>95%）；超 48h 清单（BR-118）。
- `GET /fin/cost/pending-sessions`、`GET /fin/cost/complete-rate`。

### CST-02 录入抽屉
- GMV/退款只读自 B9 已核准报告；成本项可编辑；冲话费可勾选带入。
- 提交 `POST /fin/cost/{sessionCode}`；草稿/已提交；clientToken。
- 勾稽：若本场已有未冲销分成合计与利润侧预期不平 → **1143 行内提示**（录入阶段若尚无利润则跳过）。

### CST-03 核准前编辑
- `PUT`；BUG-054/071：核准前可编辑留痕。

### CST-04 财务核准
- ConfirmDialog 汇总（BUG-048）→ `PUT .../confirm` → CONFIRMED → 触发利润计算。
- 期间 LOCKED → 1142。

### CST-05 更正单
- 核准后更正：红冲蓝补；`POST .../correction`；原因必填 1144；**不自动冲销分成单**——提示「请到分成单核对；冲销不回滚本更正」【已定】。

### CST-06 48h 督办
- 红标 + 抽屉清单；可写 B3 WARNING 待办（可选）。

## 2. 利润核算 `/ims/fin/profit`（PRF）

### PRF-01 列表与口径
- 筛选场次/平台/日期/计算状态；列含三级利润、净利率、状态。
- `GET /fin/profit/list`。

### PRF-02 详情瀑布与快照
- `GET /fin/profit/{sessionCode}`；公式快照只读。

### PRF-03 手动重算
- ConfirmDialog → `POST /fin/profit/recalc/{sessionCode}`；新版本；历史 `GET .../history`。
- 重算后按新利润**可再生成/补充分成**（引擎策略：未发放可替换待审单；已发放须冲销后补，**冲销仍不回写利润**）【本清单裁定，S-03】。

### PRF-04 异常净利率
- `GET /fin/profit/abnormal`（2σ）；可推送告警事件供 B23。

## 3. 分成规则 `/ims/fin/share/rule`（RUL）

### RUL-01 列表与创建编辑
- 阶梯编辑器；比例校验 BUG-045；启停 BUG-046；版本+1；历史单不受影响（FIN-S-R5）。
- 接口：list/POST/PUT/DELETE。

### RUL-02 试算
- `POST /fin/share/simulate`；逐档明细。

### RUL-03 优先级冲突
- 1147 须显式确认覆盖。

---

## 4. 分成单 `/ims/fin/share/result`（SHR）

### SHR-01 列表与自动生成
- 利润完成自动生成 PENDING_AUDIT。
- R7 仅本人；R9 脱敏。

### SHR-02 双审
- R3 财务审 + R4 业务审；bothPassed → AUDITED；1148/1149。
- 驳回走冲销通道（红冲分录），**不**改成本/利润状态【已定】。

### SHR-03 发放登记
- AUDITED → 凭证可选 + 备注 → PAID_OFF。

### SHR-04 冲销
- 仅 AUDITED/PAID_OFF；原因必填 1144；→ REVERSED；写 redEntries；**不反向联动成本/利润**；1143 若不平则告警保留。
- 对账/汇总 **排除 REVERSED**【已定】。
- 已冲销不可再冲 1150。

### SHR-05 冲销明细弹窗
- 红括号金额；「新单已补」链接（若有）。

## 5. 利润看板 `/ims/fin/dashboard`（DSH）

### DSH-01～05 总览/趋势/结构/下钻/分成汇总

- 下钻至场次 → 可开 B9 台账详情或本模块利润详情。

### DSH-06 导出
- XLSX/PDF → 导出中心；R9 无金额明文。

## 6. 利润反查 `/ims/fin/profit-trace`（TRC）

### TRC-01 场次级反查
- 输入场次号/账号/日期 → 展示利润 ← 成本明细 ← 分成单（标注是否已冲销）← 直播报告只读链。
- 本批不实现 DC 全图；接口本批提供 `GET /admin-api/ims/fin/profit-trace`（聚合），权限码 `ims:fin:profit-trace:query`；B27 可改读 DC【S-02】。

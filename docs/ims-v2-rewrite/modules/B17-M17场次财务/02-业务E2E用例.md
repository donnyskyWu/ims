## 1. 菜单与权限（6）

### X-01 六叶菜单（A-11）
- **步骤**：`test_admin` 看「场次财务」下菜单。
- **预期**：成本录入、利润核算、分成规则、分成单、利润看板、利润反查；无「结算单」。

### X-02 R9 脱敏
- **步骤**：`test_r9` 打开成本/利润/分成单/看板。
- **预期**：金额均为 `***`；无核准/审批/发放/导出。

### X-03 R7 本人分成
- **步骤**：`test_r7` 打开分成单列表。
- **预期**：只见自己为分成对象的单据。

### X-04 R5 协录
- **步骤**：`test_r5` 对本队已核准场次打开录入；对他队场次。
- **预期**：本队可写；他队无写或无权。

### X-05 无权限隐藏
- **步骤**：各角色检查核准/双审/冲销按钮。
- **预期**：无权限不显示按钮。

### X-06 R2 无菜单
- **步骤**：行政账号看侧栏。
- **预期**：无「场次财务」。

## 2. 成本主链（10）

### CST-E01 待录入可见已核准
- 打开成本录入：见 `S-CONF-1`，不见 `S-LIVE-1`。

### CST-E02 录入并提交
- 对 `S-CONF-1` 录入佣金/投放等，提交 → 已提交；GMV/退款只读正确。

### CST-E03 核准弹窗（BUG-048）
- 点财务核准：弹窗含场次、成本合计、5 分钟算利润提示；确认 → 已核准。

### CST-E04 未核准场次拦截（1141）
- 对 `S-LIVE-1` 尝试录入 → 提示不可录。

### CST-E05 核准前编辑留痕（BUG-054）
- 提交后核准前改金额保存成功并有留痕。

### CST-E06 更正单
- 核准后更正：原因必填；红冲蓝补可见；分成单状态不变（不自动冲销）。

### CST-E07 完整率卡（BR-107）
- 指标卡完整率随录入变化。

### CST-E08 超 48h（BR-118）
- `S-CONF-2` 红标，督办清单可打开。

### CST-E09 期间锁定（1142）
- 管理员锁定期间后录入/更正失败提示已结账。

### CST-E10 R5 协录
- `test_r5` 对本队场次可写，对他队不可。

## 3. 利润（8）

### PRF-E01 自动出利润
- 核准后等待/触发后，利润列表出现 `S-CONF-1`，状态已计算。

### PRF-E02 详情快照（BR-108）
- 打开详情见公式快照与三级利润。

### PRF-E03 重算
- 手动重算 → 版本+1；历史时间轴可见。

### PRF-E04 未核准读利润（1145）
- 无成本核准场次打开利润详情 → 提示未计算。

### PRF-E05 异常清单
- 异常 Tab/页有偏离标记（可用造数极端净利率）。

### PRF-E06～E08 列表筛选、R7 本人场次、R9 脱敏。

## 4. 规则与分成（14）

### RUL-E01 创建固定比例规则（BUG-045）
- 比例 0 或 >1 校验失败；合法 20% 保存成功。

### RUL-E02 阶梯试算（BR-109）
- 试算见逐档明细。

### RUL-E03 停用不影响历史（BUG-046）
- 停用提示历史单不受影响；列表历史单仍引用旧规则名。

### SHR-E01 自动生成分成单
- 利润完成后分成单列表出现待审单。

### SHR-E02 双审生效
- 仅 R3 通过仍待审；再 R4 通过 → 已审。

### SHR-E03 错角色（1149）
- R5 无审批按钮或提交失败。

### SHR-E04 发放登记
- 已审单发放 → 已发放；凭证可选。

### SHR-E05 冲销不回滚利润（已定）
- 对已发放单冲销填原因 → 已冲销；打开该场次成本仍为已核准、利润仍为已计算；冲销明细红括号。

### SHR-E06 1143 告警保留
- 构造勾稽不平（如手工造数）：成本/利润页或对账视图出现 1143 提示，不阻断已核准记录查看。

### SHR-E07 对账排除已冲销（已定）
- 对账/看板分成汇总：不含 `SHR-REV` 金额；含已发放未冲销。

### SHR-E08 重复冲销（1150）
- 对已冲销再冲 → 失败提示。

### SHR-E09 未双审不可冲
- 待审单无冲销或 1150。

### SHR-E10 R7 本人分成
- 只见自己为对象的分成单。

## 5. 看板与反查（8）

### DSH-E01 总览指标
- 周期查询见 GMV/成本/净利；刷新时间展示。

### DSH-E02 趋势与结构
- 图可见；结构含佣金等切片。

### DSH-E03 下钻到场次
- 下钻点击场次打开利润或台账详情。

### DSH-E04 分成汇总排除冲销
- 与 SHR-E07 一致。

### DSH-E05 导出
- R3 可导出；R9 无明文金额。

### TRC-E01 反查
- 输入 `S-CONF-1`：见利润、成本项、分成单（含已冲销标记）。

### TRC-E02 无 DC 全图
- 页内无强制「关系图全屏」依赖 B27 的阻塞；列表/链可读。

### TRC-E03 无权深链
- R7 打开他队场次反查 → 无权。

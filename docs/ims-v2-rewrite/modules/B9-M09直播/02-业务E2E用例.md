## 2. 开播登记与风控（18）

### REG-E01 主链路：绿色自动放行 → 开播 → 下播（REG-01/03/04/07/08）
- **步骤**：`test_r5` 进直播场次，点「新建场次登记」；账号选 `AC-DYS-USE`，实名人默认带出「测试实名甲」，设备选 `AS-LV-1`，主题「测试直播主链路」，计划开播填 1 小时后、计划下播 4 小时后，提交。
- **预期**：平台自动显示「抖音」且不可改；提交后自动跳到场次详情「风控登记」Tab，五项全部绿色通过，风险分 < 40，级别「绿」，状态「已放行」，场次 ID 形如 `IMS20261013DYS0001`；点「确认开播」→ 状态「直播中」；点「确认下播」→ 状态「已下播」，工作台出现「下播录入」待办。

### REG-E02 BUG-063：实名人下拉范围（REG-01）
- **步骤**：`test_r5` 新建登记，展开实名人下拉并分别搜索甲 / 乙 / 丙 / 丁 / 停 / 删。
- **预期**：甲、乙、丙、丁都在下拉中（丙显示红字「证件已过期」）；「测试实名停」「测试实名删」搜不到。

### REG-E03 BUG-063：选过期实名人红字预警但可提交、风控判红（REG-02/03，BR-013）
- **步骤**：新建登记选实名人「测试实名丙」，看字段下方提示；其余正常填写后提交。

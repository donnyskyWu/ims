## 0. 约定

### 0.1 编号
`WRK` 竞品作品、`ACC` 竞品账号、`LIB` 竞品库、`SUB` 分析提交、`AUD` 审核工作台、`CMP` 对比热度、`UP`/`BG`。

### 0.2 范围

| 类别 | 内容 |
|------|------|
| 侧栏 | L2「竞品分析」3 叶：竞品作品 `/ims/comp-analysis/work`、竞品账号 `/ims/comp-analysis/account`、竞品库 `/ims/comp-analysis/library` |
| P1 作品 | Tab 全部/爆款/低分；阈值只读 B12；导出；详情只读 |
| P2 账号 | Tab 全部/高粉/低粉；平台 Tab 可保留；链采集配置 |
| P3 竞品库 | V3 资产库卡片/列表；别名；详情版本轴 |
| 无菜单二级 | **提交分析** `/ims/comp/analysis/submit`（工作台待办 + 库工具栏「提交分析」）；**审核工作台** `/ims/comp/audit`（待办入口）【已定 A-18】 |
| P4 对比热度 | **竞品库页内 Tab**【已定 A-18】：对比报告 + 热度排行 |
| 审核规则 | 初审 R8、终审 R4；**提交人不能审自己 1057**；**R1 不审**【已定】；不进 FLOW（模块自有审核，同 CONTENT 精神；B4 仅依赖为「可复用回避基建」，不建竞品 FLOW 模板）【本清单裁定，S-02】 |

| **不做** | 把提交/审核做成侧栏 L3；与 COLLECT 配置菜单合并；H5 专包本期可做 Web 同构优先，H5 路由可留兼容【P-3】 |
| 复用 | B0b；B12 外部快照与阈值；B3 待办深链 |
| E2E | `b14.py` |

### 0.3 权限码
监测 query/export：R1/R4/R5/R6/R9（IP 组范围）。
`ims:comp:analysis:submit` R5/R6；`ims:comp:audit:first` R8；`ims:comp:audit:final` R4；`ims:comp:asset:query` 广；`ims:comp:asset:write` R1/R4（别名/归档）；**无** `ims:comp:audit:*` 授予 R1【S-03】。

### 0.4 错误码
监测沿用通用；V3 COMP **1171～1177**；回避 **1057**。

| 码 | 说明 |
|----|------|
| 1171 | 数据来源必填（合规） |
| 1172 | 同人同月同竞品重复提交 |
| 1173 | 退回必须填原因 |
| 1174 | 三要素不齐不可通过 |
| 1175 | 3 轮退回升级 |
| 1176 | 越级终审 |
| 1177 | 别名归并键冲突 |
| 1057 | 不能审自己 |
| 1251 | 阈值未配置（空态提示） |

### 0.5 表
只读消费 B12：`ims_ext_work` / `ims_ext_account`（命名以 B12 落地为准）。
V3 写模型：**新建** `ims_comp_analysis`（CA 单）、`ims_comp_audit_round`、`ims_comp_asset`（CP 档案）、`ims_comp_asset_version`、`ims_comp_alias`；不建物理外键；ID 字符串。

### 0.6 字典
CompAnalysisStatus：DRAFT/SUBMITTED/STORED/REJECTED；CompeteStatus：TRACKING/PAUSED/ARCHIVED；平台 dict_platform_type。

## 0. 约定

### 0.1 编号
`FP-B12-<缩写>-<序号>`：`TSK` 采集任务、`LOG` 采集日志、`EXT` 竞品账号、`KW` 关键字、`META` 元数据、`THR` 阈值、`HID` 隐藏能力（凭账号/数据源/内部/质量）、`UP` 上游、`BG` 后台。

### 0.2 本批范围

| 类别 | 内容 |
|------|------|
| 侧栏 | L1「日常运营」→ L2「数据采集」**6 叶子**：采集任务 `/ims/collect/task`、采集日志 `/ims/collect/log`、竞品账号配置 `/ims/collect/external/account`、竞品关键字配置 `/ims/collect/external/keyword`、元数据维护 `/ims/collect/metadata`、阈值规则 `/ims/collect/threshold` |
| 兼容 | `/ims/collect` → 重定向 task |
| 采集任务 P5 | 单账号 / 统一任务 / 外部配置；启停、立即执行；**禁止 Cookie 字段**（凭证在 B7 账号采集 Tab） |
| 采集日志 P5b | 分页、详情 typeResults、24h 成功率；失败链到账号采集 Tab |
| 竞品账号 P2a | 外部主体 CRUD、CSV 导入；工具栏「租户采集凭账号」「外部 HTTP 数据源」 |
| 关键字 P2b | CRUD |
| 元数据 P4m | 实体映射/字段；供 BI0 只读 |
| 阈值 P4 | Tab：预警/粉丝/作品/账号覆盖；供 INT/COMP/MON/ALERT **只读引用** |
| 隐藏 | P6 质量并入日志；P2t 凭账号；P2c 数据源；P1 内部；订单配置禁止 JDBC（1243） |
| 外部环境 | **采集器真实环境**【已定 D-06】；开发期适配层可 MOCK 并界面标注；提测说明列模拟项 |
| 复用 | B0a 采集适配、`@job`、导出；B0b 全套已建组件 + AccountSelect；B7 采集 Tab |
| E2E | `tools/e2e_seed/b12.py` |

### 0.4 错误码
通用 1001/1008/1216/1500～1504；COLLECT **1241～1250**。

| 码 | 提示 | 用于 |
|----|------|------|
| 1241 | 凭据无效 / Cookie 失效 | 执行失败详情 |
| 1242 | 平台不支持 | 任务/配置 |
| 1243 | 禁止 JDBC / 直连订单库 | 订单配置 |
| 1244 | 统一任务成员不合法 | ensure-unified |
| 1245 | 外部配置不存在或未启用 | Channel-D |
| 1246 | 阈值表达式/分类非法 | THR |
| 1247 | 元数据实体编码冲突 | META |
| 1248 | 采集器未绑定 / 不可达 | run（真实模式） |
| 1249 | 任务状态不允许该操作 | 启停/删除 |
| 1250 | 预留 | — |

### 0.5 表（不建物理外键；ID 字符串）

| 表 | 说明 |
|----|------|
| `ims_collect_task` | 任务：name、platform、method、account_id、collect_config_id、cron、status、last/next_run |

### 0.6 字典

## 1. 采集任务（P5）

### FP-B12-TSK-01 任务列表与筛选
- 筛选：名称、平台、方式、频率、状态；列含绑定对象、cron、上次/下次、状态。
- 接口：`GET /admin-api/ims/collect/task/page`。

### FP-B12-TSK-02 新建/编辑任务
- 单账号：AccountSelect 必填；统一：成员表；外部：竞品配置必选且 account_id 必须 null；**无 Cookie 控件**。
- 接口：`POST/PUT/DELETE /collect/task/{id}`。

### FP-B12-TSK-03 统一任务成员
- `POST /collect/task/ensure-unified`（及外部统一）；1244。

### FP-B12-TSK-04 启停 / 立即执行
- `POST …/start|stop`；`POST …/run` → 跳转日志并带 taskId；真实采集器或 MOCK 标注。

### FP-B12-TSK-05 查看日志入口
- 行操作跳转 P5b。

## 2. 采集日志（P5b）

### FP-B12-LOG-01 日志列表与统计卡
- 顶栏 24h 成功率、连续失败账号；筛选任务/账号/状态/日期。
- `GET /collect/log/page`。

### FP-B12-LOG-02 日志详情
- typeResults 折叠；Cookie 失效 / 未绑定 Collector → 链 B7 账号采集 Tab。
- `GET /collect/log/{id}`。

### FP-B12-LOG-03 手工补录入口
- 日志页工具栏；`POST /collect/manual-fill`；质量 summary `GET /collect/quality/summary`（无侧栏）。

---

## 3. 竞品账号 / 关键字 / 隐藏入口

### FP-B12-EXT-01 竞品账号配置页
- CRUD、批量导入 CSV、批量删除；Alert：配置行不嵌 Cookie。
- `GET/POST/PUT/DELETE /collect/external/account/**`；`POST …/import`。

### FP-B12-EXT-02 租户采集凭账号（P2t）
- 工具栏入口抽屉；`/collect/external/credential/**`。

### FP-B12-EXT-03 外部 HTTP 数据源
- 工具栏抽屉；`/collect/external/source/**`。

### FP-B12-KW-01 关键字配置
- 独立页 CRUD；`/collect/external/keyword/**`。

## 4. 元数据（P4m）

### FP-B12-META-01 实体列表与未映射表
- `GET /metadata/list`、`unmapped-tables`、`table-columns`。

### FP-B12-META-02 新建/编辑实体与字段
- `POST /metadata/create`；`PUT /metadata/{id}`；`PUT …/fields`；编码冲突 1247。

### FP-B12-META-03 BI0 只读读口
- `GET /metadata/entity/{code}/fields`（供 B24）；页脚链到指标自定义查询（B24 未上线时提示建设中）。

## 5. 阈值规则（P4）

### FP-B12-THR-01 四 Tab 阈值 CRUD
- Tab：预警阈值/粉丝阈值/作品阈值/账号覆盖；category 必填。
- `GET /threshold/list`；`POST/PUT/DELETE /threshold/**`；非法 1246。

### FP-B12-THR-02 供下游只读
- INT/COMP/MON/ALERT **不重复配置**；改阈值后下游列表过滤即时按新值（缓存≤1 分钟，【裁定】）。

## 6. 隐藏：内部 / 订单

### FP-B12-HID-01 内部采集配置
- 管理员；企微/个微；链自任务编辑说明。
- `GET/PUT /collect/internal/{platform}`。

### FP-B12-HID-02 订单采集配置
- `GET/PUT /order-config`；禁止 JDBC 连接串（1243）。

## 7. 上游 / 后台

### FP-B12-UP-01 B7 采集 Tab 交叉

### FP-B12-UP-02 采集适配真实/模拟

## 2. 树与组 CRUD（10）

### TR-01 空树与新建大组（TR-02/03，BUG-026）
- **步骤**：在干净租户或清空可见组后（造数可另备空租户说明）看空态；`test_r4` 点「新建大组」，组名「测试大组丙」，保存。
- **预期**：空态有「新建大组」；保存成功，左树出现大组，计数 (0/0/0)。

### TR-02 新建小组（TR-04）
- **步骤**：选中大组甲 →「新建小组」，组名「测试小组丙」，上级为大组甲，保存。
- **预期**：树在大组下出现小组；类型 Tag「小组」。

### TR-03 同父重名（TR-03）
- **步骤**：在大组甲下再新建同名「测试小组甲」。
- **预期**：提示组名重复（中文），不创建。

### TR-04 搜索命中小组（TR-02，BUG-025）
- **步骤**：搜索框输入小组甲关键字。
- **预期**：展开父大组并高亮小组；无命中时「无匹配的 IP 组」。

### TR-05 编辑与不可改类型（TR-05）
- **步骤**：编辑小组甲改备注与等级；观察组类型。
- **预期**：备注/等级可存；类型只读为大组/小组。

### TR-06 小组改上级（TR-05）
- **步骤**：若存在两大组，将小组丙改挂到另一大组。
- **预期**：成功；树位置更新；不能选自己或子孙。

### TR-07 停用组（TR-06）
- **步骤**：停用小组丙。
- **预期**：节点灰色「停用」；IpGroupSelect 新建账号时不可选该组。

### TR-08 有数据禁止删除（TR-07）
- **步骤**：对已有成员或账号的小组甲点删除。
- **预期**：提示「仍有成员/账号/关联作者，禁止删除」。

### TR-09 无数据可删（TR-07）
- **步骤**：删除无成员无账号无作者的空小组（如新建后立即删）。
- **预期**：成功；树刷新；空态符合 BUG-026。

### TR-10 基本信息 Tab（TR-08）
- **步骤**：选中小组甲，看基本信息。
- **预期**：组名、类型、上级、组长、等级、状态、时间中文展示完整。

## 4. 账号绑定与 1223（10）

### ACC-01 大组不可绑（ACC-02）
- **步骤**：选中大组甲 → 账号绑定 → 尝试绑定。
- **预期**：写操作不可用或提示「大组不可绑定账号」。

### ACC-02 小组绑定成功与物化（ACC-02，B7-01）
- **步骤**：小组甲（仅 1 名作者「作者-单」）→ 绑定 `AC-DYS-POOL`。
- **预期**：成功；列表出现该账号；打开 B7 抖音详情，IP 组显示「测试大组甲 / 测试小组甲」，作者自动为「作者-单」。

### ACC-03 跨组重复绑定（ACC-02）
- **步骤**：在小组乙对已属小组甲的账号再绑。
- **预期**：提示「账号已属于其他 IP 组：…」。

### ACC-04 双作者无主 → 1223（ACC-02，B7-01）
- **步骤**：小组乙（作者-双A/双B，无主作者）→ 绑定一台池中账号。
- **预期**：失败，提示需指定主作者（1223 中文）；引导去关联作者 Tab。

### ACC-05 设主作者后可绑（ANC-03，ACC-02）
- **步骤**：小组乙关联作者 Tab 将「作者-双A」设为主作者 → 再绑定账号。
- **预期**：绑定成功；账号作者物化为作者-双A。

### ACC-06 解绑不清空作者（ACC-03）
- **步骤**：解绑刚绑账号，再开 B7 详情。
- **预期**：IP 组为 —；作者名仍可保留；有「作者引用仍保留」类提示或符合清单。

### ACC-07 B7 新建账号必选 IP 组（B7-02/03）
- **步骤**：`test_xz` 或 admin 在抖音页登记账号，不选 IP 组保存；再选大组保存；再选小组甲保存。
- **预期**：不选 → 必填校验；选大组 → 不可或 1203；选小组甲 → 成功且作者按解析回填。

### ACC-08 B7 编辑历史空 IP 组（B7-02）
- **步骤**：打开仍无 IP 组的历史账号（若造数保留）→ 编辑保存不选组。
- **预期**：须补选小组后方可保存。

### ACC-09 列表筛 IP 组（ACC-04）
- **步骤**：抖音页 QueryBar 按小组甲筛选。
- **预期**：仅出该组账号。

### ACC-10 级联：作者→账号（SEL-03，ACC-05）
- **步骤**：在作者管理编辑某作者主推号：先选作者归属组，再开 AccountSelect。
- **预期**：选项限于该小组已绑账号；选其他组账号应 1127 或不可见。

## 5. 关联作者（6）

### ANC-01 添加作者（ANC-02）
- **步骤**：小组甲 → 关联作者 → AuthorSelect 添加「作者-主」，保存。
- **预期**：列表出现；非 UserSelect；树作者数 +1。

### ANC-02 大组不可关联（ANC-02）
- **步骤**：大组甲尝试关联作者。

### ANC-03 设主与降级（ANC-03）
- **步骤**：组内两位作者时设 B 为主，再设 A 为主。
- **预期**：始终至多一名「主作者」标记；原主降级。

### ANC-04 移除主作者不递补（ANC-04）
- **步骤**：移除当前主作者。
- **预期**：成功；提示请重设；不自动把另一人设主。

### ANC-05 AuthorSelect 非用户（ANC-02，AU-02）
- **步骤**：添加关联作者抽屉，确认控件为作者选择。
- **预期**：选项来自作者档案，不是系统用户列表。

### ANC-06 无权限只读（ANC）
- **步骤**：`test_r9` 看关联作者 Tab。
- **预期**：无添加/设主/移除。

## 7. 作者管理（8）

### AU-01 列表与跨组查询（AU-01）
- **步骤**：切到「作者管理」，按组名/关键字筛选。
- **预期**：可跨组看到作者；列含归属组、类型、状态中文。

### AU-02 新建作者（AU-02）
- **步骤**：新建，作者名「作者-新」、类型「短视频」、归属小组甲，保存。
- **预期**：成功；编号形如 `AU-20261013-001`；列表可查。

### AU-03 主推号共池（AU-02）
- **步骤**：编辑作者，主推号选不属于其归属组的账号。
- **预期**：不可选或提示不在同一 IP 组账号池。

### AU-04 停用后选择器不可见（AU-04，SEL-02）
- **步骤**：停用「作者-新」；在关联作者添加里搜索。
- **预期**：停用作者不可选。

### AU-05 删除引用阻挡（AU-04）
- **步骤**：删除仍被账号 `author_user_id` 引用或仍关联组的作者。
- **预期**：1502 类中文提示；无引用则可删。

### AU-06 详情轻量（AU-05）
- **步骤**：打开作者详情。
- **预期**：基本信息与关联组可见；无报错；可不含复杂图表。

### AU-07 导出（AU-06）
- **步骤**：作者列表导出 → 消息中心领取。
- **预期**：异步成功；IP 组运营页无导出按钮（BUG-024）。

### AU-08 禁 UserSelect 当作者（AU-02）

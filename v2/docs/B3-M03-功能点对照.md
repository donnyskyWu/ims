# B3 · M03 个人工作台 · 功能点对照

对照 `modules/B3-M03个人工作台/01-功能点清单.md`（28 个功能点）。接口以 B0a 路径为准：`/admin-api/ims/todo/my`、`/admin-api/ims/message/my`、`/admin-api/ims/workbench/dashboard`。`/admin-api/ims/auth/workbench/*` 只是别名，页面不依赖它。

告警的存库值沿用 B0a 的 `ALERT`（字典「告警」）。材料里的 `ALARM` 只在查询时映射到 `ALERT`，不入库。逾期不是独立状态：`PENDING` 且截止时间早于当前时刻显示「已逾期」，并排在前面。关闭待办写成 `DONE`（字典「已处理」）。

本批四张业务卡计数固定为 0。目标业务页未交付，跳转只到占位页，不自动关闭待办。单据已删除用 `source_type=DOC_GONE` 返回 1297，前端再调用 complete。1298 保留，未注册、未抛出。消息中心读写 `ims_sys_message`，与 B2 通知运维页的 `ims_sys_notify_record` 不是同一张表。

# B7 · M07 公司账号管理对照表

对照 01-功能点清单 v1.0（张武 2026-10-13 审过）。实现都在 `v2/`。接口前缀 `/admin-api/ims/`。业务 E2E 只作验收依据，本批提测不跑 Playwright。

| 功能点 | 实现 | 说明 |
| --- | --- | --- |
| PA-01 | `account/platform.py` `page`；`PlatformView.vue` | 五平台共用一页，`platform` 来自路由 meta |
| PA-02 | `POST /corp/account` | 在库、责任人空；`WECHAT_OFFICIAL` 写入改为 `WECHAT_MP`；容量不足 1222；实名不一致只告警 |
| PA-03 | `PUT /corp/account/{id}` | 平台与编号不可改；已注销 1001 |
| PA-04 | 详情抽屉四个页签 | 基本信息、采集、领用时间线、关联资产 |
| PA-05 | 注销 / 删除 | 在用不可注销；删除仅在库且无后续记录 |
| PA-06 | `GET /corp/account/export` | 异步 xlsx；金额按权限打码 |
| PA-07 | `asset-bind` / `assets` | 全量对比 ACTIVE / RELEASED；报废 1015 |
| PA-08 | `GET /master/selector/account` | `AccountSelect` 走真实选择器；空且无关键字 1221 |
| PER-01 | `personal.py` `page` | 个人账号只进台账 |

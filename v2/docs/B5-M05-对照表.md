# B5 · M05 公司资源对照表

接口前缀 `/admin-api/ims/`。本批不建账号管理、设备管理菜单，证件页为三个 Tab。

| 功能点 | 接口 | 实现 |
|--------|------|------|
| CO-01～07 | `/corp/resource/company/*` | `app/domains/resource/company.py`、`router.py`；页面 `views/resource/CompanyView.vue` |
| CO-08 | `GET /master/selector/company` | `resource/selector.py`；`CompanySelect.vue` |
| RN-01～06 | `/corp/resource/realname/*` | `resource/realname.py`；`RealnameView.vue` |
| RN-07 | `GET /master/selector/person` | `selector.py`；`RealNameSelect.vue`（含 `certExpired`） |
| SIM-01～06、08 | `/corp/resource/sim-card/*` | `resource/sim.py`；`SimCardView.vue` |
| SIM-07 | `GET /master/selector/sim-card` | `selector.py`；`SimCardSelect.vue` |
| CERT-01～07 | `/cert/archive/list|upload|{id}|review|file-url|digital-metrics` | `cert/archive.py`、`cert/security.py`；`CertificateView.vue` 档案 Tab |
| EXP-01～05 | `/cert/expire/list|stats|scan|{id}/renew|remind` | `cert/expire.py`；预警 Tab；任务 `cert_expire_scan` |
| EXP-06 | `cert.service.is_locked` | `cert/service.py` |
| SEC-01～05 | `/cert/security/view|level-config|view-logs|risk-report` | `cert/security.py`；分级 Tab |
| BG-01 | 菜单种子 | `app/catalog.py` `公司资产 / 资源管理`；`/ims/cert/expire` 重定向 |
| BG-02 | 字典 | `dict_corp_status`、`dict_cert_*`、`dict_sim_operator`、`dict_payment_cycle`、`dict_yes_no` |
| BG-03 | Ref | 模型 `Ref(...)`，迁移不建物理外键 |
| BG-04 | OCR mock | `integrations` 适配器 `ocr`；上传场景 `CERT` 回填 |
| BG-05 | 通知模板 | 参数 `notify.cert.yellow/red/locked/remind/reject`；工作台深链证件管理 |
| BG-06 | 造数 | `tools/e2e_seed/b5.py`（仅 test/e2e） |

水印文本为查看人姓名、登录账号、时间到秒。驳回为逻辑删除并通知上传人。换证上传带 `renewOfCertId` 跳过重复校验。

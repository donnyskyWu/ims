# B6 · M06 设备对照表

接口前缀 `/admin-api/ims/`。设备领用不走审批。状态六值：待审核、使用中、已归还、闲置、维修中、已报废。手机设备不进资产穿透和完整率。

| 功能点 | 接口 | 实现 |
|--------|------|------|
| PH-01～07 | `/corp/device/phone/*` | `app/domains/device/phone.py`、`router.py`；页面 `views/device/PhoneView.vue` |
| PH-08 | `GET /master/selector/phone` | `device/phone.py`；`AssetSelect.vue` 的 `kind="phone"` |
| DEV-01～02 | `/corp/device/office/page`、`/corp/device/live/page` | `device/ledger.py`；`LedgerView.vue` |
| DEV-03～06、08 | `/asset/ledger` 登记、编辑、详情、删除、导出 | `device/ledger.py` |
| DEV-07 | `POST /asset/ledger/import` | CSV，最多 200 行，部分失败不回滚；模板 `ims-web/public/templates/asset-purchase.csv` |
| DEV-09 | `GET /master/selector/asset` | `device/ledger.py`；`AssetSelect.vue` 接真实数据 |
| LC-01～06 | 领用、流转、归还、报废、标记状态、时间线 | `device/flow.py`。归还后责任人=办理行政。使用中须先归还才能报废 |
| FWD-01～03 | `/asset/forward/detail|trace|export` | `device/forward.py`；`ForwardDrawer.vue`。报告 300 秒，过期 1001 |
| REV-01～04 | `/asset/reverse/by-person|by-account|by-session|export` | `device/reverse.py`；`ReverseDrawer.vue`。按账号、按场次本批不渲染入口 |
| VER-01～05 | `/asset/verify/run|metrics|batches|errors|task` | `device/verify.py`；`VerifyDrawer.vue`。本批只跑 `asset_person`。工单含待复审 |
| VER-06 | 定时任务 `asset_verify_overdue` | 逾期升级一次，钉钉走现有 mock |
| BG-01 | 菜单与权限 | `app/catalog.py`「设备管理」三叶；`/ims/asset/ledger|reverse|verify` 重定向办公设备页 |
| BG-02 | 字典与通知 | `dict_asset_*`、`dict_phone_*`；参数 `notify.asset.checkout/transfer/verify.*` |
| BG-03 | 选择器 | `AssetSelect` 真实源；`SimCardSelect` 透传 `unboundOnly` |
| BG-04 | Ref | 模型 `Ref(...)`，迁移不建物理外键。已绑手机卡停用/删除 1502 |
| BG-05 | 定时任务 | `asset_verify_full` 周一 02:00、`asset_verify_increment` 每日 02:00、`asset_verify_overdue` 每日 09:00；页面 `/ims/system/job` |
| BG-06 | 造数 | `tools/e2e_seed/b6.py`（仅 test/e2e） |
| BG-07 | B5 回补 | 手机卡列表与详情显示绑定手机；实名人详情「反查资产」 |

表：`ims_master_phone` 加列；新建 `ims_asset_ledger`、`ims_asset_event`、`ims_asset_bind`、`ims_asset_purchase_batch`、`ims_asset_verify_batch`、`ims_asset_verify_task`。手机时间线复用 `ims_sys_timeline`（`biz_type=PHONE`），不另建第七张业务表。`ims_asset_bind` 本批只建表，账号与场次写入留给 B7 / B9。

R5 角色种子仍是部门范围，设备列表在服务里按「本人为责任人」过滤。无权限按钮不渲染。离职员工沿用 B1，不能登录。

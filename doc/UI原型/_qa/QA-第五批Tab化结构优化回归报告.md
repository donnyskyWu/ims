## 三、踩坑与经验（累积第 11~13 条）

- **经验 11（源码字符串匹配的转义陷阱）**：源码 HTML onclick 属性内的函数调用是 `setTab(\'dc\'...`（含反斜杠转义）。测试用 `SRC.indexOf("setTab(\\'dc\\'")` 时，测试文件里的字面量经过一层解析后可能退化——**稳妥写法是渲染断言优先（sandbox 调 PAGES.dc() 检查输出），字符串匹配只作辅助**
- **经验 12（测试断言的数据假设）**：写断言前必须 Grep/Read 确认真实函数名（meetMinGen 而非 minutesGen）与真实页面键清单（PAGES 共 18 键，无 org/datarp——组织在 workbench/auth、数据上报在 report 页内 Tab）
- **经验 13（结构演进的旧断言适配）**：页面结构重排后，旧测试断言失败≠代码 Bug——先 diff 断言所依赖的旧结构（维度 pills 位置、报表树位置），把断言的渲染前置改为新结构的对应 Tab，保持**行为验证**（biOpenRpt 存在、无 toast 占位）不变

## 桩方法论（累积第 7 条）

前 6 条沿用（最小 DOM 桩 / setTimeout 同步 / _mk 增删 / 声明提升重覆盖 / formValidate 预置值 / doConfirm 手动触发）。

**第 7 条：沙箱二次执行源码时，new Function 的参数名不得与源码顶层 const/let 声明同名**（如 `state`、`RTPLS`、`FLOWS`、`ALERTS`）——否则直接 `Identifier 'xxx' has already been declared` 语法错误（非运行时异常）。正确做法：`sandbox(expr, preset)` 工具函数仅以 `document/setTimeout/clearTimeout/console` 为参数，preset 前缀声明桩函数（var 赋值覆盖），再拼接 SRC 与断言表达式；需要验证的数据同步断言（如 L5 fields 计数）应在沙箱内 return 出来比对，而不是拿外部缓存对象（沙箱内是独立数据副本）。
